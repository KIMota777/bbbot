## 2. ЧТО СДЕЛАНО (круг 1 + советник, проверено запуском)

### Живой бот (`bot_rsi.py`, `bot.py`, `config.py`)
- Персистентность состояния с атомарной записью (tmp + `os.replace`); сверка при старте
  (`reconcile_start`): режим one-way/hedge, позиция с биржи, расхождение -> `handle_orphan` + пауза.
- Округление цены к кратному `tickSize` через Decimal (BTC tick 0.10, SOL 0.010) — проверено на
  39 ценах всех 5 монет, все кратны шагу. Тот же фикс в `bot.py:_fmt_price`.
- `_last_closed_pnl`: запрос со `startTime=opened_ts`, отбор по `updatedTime`, суммирование частей,
  возврат `None` вместо выдуманного 0.0. Чужая сделка -> None (было −13.7), пусто -> None (было 0.0).
- Потолок общей маржи в коде (`MAX_TOTAL_MARGIN_FRACTION=0.8`), дневной лимит −10% -> пауза 12ч,
  стоп по просадке −25% -> `halted` (снимается только руками).
- Уведомления (Telegram через env, тихий no-op без токена); счётчик серии ошибок API.
- Ген `grid_w_atr_k` реализован через `gridlib.leg_weights` — веса LTC совпали с движком до 15 знака.
- `paper_fill` с издержками движка (тейкер 0.055%, мейкер 0.02%, слиппедж 0.03%, фандинг 0.01%/8ч).
- Кулдаун приведён к правилу движка; utf-8 в консоль (проверено под chcp 866).

### Движок (`evolution2.py`, `gridlib.py`, `build_*.py`)
- Консервативный внутрисвечной порядок: тейк в свече с доливкой пересчитывается от НОВОЙ средней
  и исполняется только если реально лежит в диапазоне свечи.

- Данные сайта пересобраны через `build_pnl_curves.py` / `build_analytics.py`.

## 3. ОСТАЛОСЬ — ЗАДАЧИ КРУГА 3 (актуальный список, ничего из этого не сделано)

Ни одна из этих находок НЕ критична для денег: критические дефекты закрыты в кругах 1-2 и
подтверждены стендами (59 проверок, 0 провалов).

**Живой бот.** `paper_fill` не моделирует ликвидацию вообще (движок сравнивает
`danger = max(p_liq, stop)`, бот — только `stop`), поэтому DRY_RUN льстит. Порог безубытка
бот считает от `self.p["tp"]`, а движок от `pos["tp_eff"]` — латентная мина. Ранний выход по
`orphan_key` не даёт повторить НЕУДАВШЕЕСЯ закрытие чужой позиции. `_EntryGate.__exit__` может
снять чужой замок. В DRY_RUN бот не может войти на баре, где закрылся предыдущий цикл, а движок может.

**Движок.** Подпись портфельных линий зашита как «ПОРТФЕЛЬ $350», хотя реально $250 (сетапы
выключены). Две правки не закреплены мутационными тестами (`entrymark`, `liqfloor`). В analytics
`wins + losses != trades` (911 + 46 = 957 при 958). Просадка LTC расходится между файлами:
29.4% в analytics против 29.3% в pnl_curves.

**Сайт.** В `list_bots()` при переписывании исчез `try/except` — если в analytics нет
`final_pct`, главная падает. API (`api_analytics`, `api_pnl_curves`, `api_finalstats`) не
защищены от битого JSON. На страницах сетапов два разных числа просадки. Список `/signals`
не передаёт признак слива.

**Протокол отбора.** Фитнес GA и выбор победителя остаются на плече отбора, а не на боевом.
`evolution11_winners.json` перезаписывается, хотя докстрока обещает сохранность. Неторгующий
геном может выиграть отбор при убыточной базе (его балл 0.00 лучше отрицательного). У `v9` нет
ни ворот, ни правила приёмки: сетап записан в победители с экзаменом хуже базы.

**Внешние данные.** `MacroSeries` может бросить при неожиданном типе ключа. `get_macro` в
`bot_rsi.py` удаляет `daily_pct5.json` старше суток, гася правку «пустышку не кэшируем».
Сайт при мёртвом источнике молча показывает другую симуляцию и кэширует её на 30 минут.

**Не прогонялся полный набор тестов** после правок: `test_patterns.py`, `test_smc.py`,
`test_signals.py`, `test_evolution8.py`, `test_news_mcp.py`, `validate.py`. Прогонялись
`compileall` (чисто) и страницы сайта (200).

## 3b. История: задачи круга 2 (СДЕЛАНЫ, оставлено для контекста)

### Живой бот — major
1. Окно ожидания PnL (`CLOSED_PNL_GRACE_SEC`) НЕ снимает позицию с ведения: `on_new_candle`
   продолжает вести уже закрытую биржей позицию (`set_trading_stop` по несуществующей позиции).
2. В том же окне срабатывает закрытие по таймауту и пишет ВЫДУМАННЫЙ PnL.
3. `sync_exchange` не сверяет СТОРОНУ позиции (в `reconcile_start` проверка есть, в цикле нет).
4. Вход не персистится ДО постановки колен: обрыв между входом и коленами -> позиция есть, в
   состоянии нет -> следующий старт закроет её как orphan.
5. `paper_fill` использует ослабленный вариант тейка («loose»), который движок объявляет недопустимым.
6. `cancel_own_orders` вырождается в глобальный `cancel_all_orders` -> сносит ручные ордера владельца.
7. `_last_closed_pnl` суммирует любые строки по символу -> ручная сделка засчитывается как PnL цикла.
8. `last_candle_ts` не сохраняется: после рестарта свеча обрабатывается повторно.

### Движок — major
1. **`test_gridlib.py` не закрепляет 2 фикса из 4**: мутация `maker` (откат `TP_MARKET_EXIT`) и
   мутация `oldliq` (откат ликвидации) проходят ВСЕ 275 проверок. Тест 9a сам пересчитывает
   ожидание через флаг и подстраивается. Нужно мутационное тестирование каждого фикса.
2. Плавающая просадка занижена: не учитывается ход внутри бара закрытия и бара входа.
3. Две разные метрики называются одинаково (`max_dd_float` в run5 поднимает пик прибылью,
   в `build_*` — нет).
4. Ключ `ruined` не доезжает до сайта (см. раздел 1).
5. Докстринг про ликвидацию врёт: формула НЕ консервативнее биржи для лонгов.

### Протокол — major
1. Ворота риска меряются на плече x5, а в конфиг уходит до x15 (`evolution4.py:423`, `e2.LEV` не
   выставляется). То же в v12.
2. У `evolution6.py` и `evolution9.py` СВОЙ протекающий харнесс — правка v4 их не коснулась.
3. `honest_eval.random_control` загрязнён неторгующими геномами (11 из 30 делают 0 сделок) —
   меряет «не торговать вовсе», а не «случайный вход».
4. `neighbour_median` не двигает дискретные гены (округление съедает sigma).
5. Мёртвые правила приёмки: v10 правило 2, v12 правило 4 физически не могут сработать.
6. `evolution11.py:148` перезаписывает `evolution11_final.json`, хотя докстрока обещает сохранность.
7. Плечо подбирается по ЗАКРЫТОЙ просадке — надо по плавающей.

### Новости — minor
1. **Регресс:** новое исключение `MacroUnavailable` доходит до сайта и роняет страницу в 500
   (`/api/sim/BTCUSDT`). Обработчик есть только у `bot_rsi.py` из 9 вызывающих.
2. Докстрока переобещает: в боевом пути падения нет, бот всё равно сутки торгует без фильтров.

### Сайт — minor

2. Признак слива счёта не отображается.
