# bbbot — торговые боты и сигнальный помощник для Bybit

Исследовательский проект: 5 торговых ботов (BTC/ETH/LTC/DOGE/SOL, линейные
перпетуалы, 15m) + сигнальный помощник по BTC (6 среднесрочных сетапов),
отобранные девятью волнами генетической оптимизации с walk-forward
экзаменами на 3.2 годах истории, и локальный сайт с графиками и аналитикой.

## Быстрый старт

```bash
pip install -r requirements.txt

# сайт: http://127.0.0.1:8000  (или start_site.bat на Windows)
python webapp/app.py

# бот (DRY_RUN по умолчанию — реальные ордера не отправляются)
python bot_rsi.py DOGE          # финальный конфиг монеты
python bot_rsi.py BTC bear      # архивные режимы: normal | bear | turbo

# сигнальный помощник BTC (не торгует — говорит, где входить)
python advisor.py
```

Для реальной торговли: ключи в переменных окружения `BYBIT_API_KEY` /
`BYBIT_API_SECRET` (без права вывода средств!) и `DRY_RUN = False` в
`config.py`. Сначала обкатка в DRY_RUN.

## Структура

| Файл | Что это |
|------|---------|
| `config.py` | все конфиги ботов (финальные + архив волн), риск-менеджмент |
| `bot_rsi.py` | живой бот: RSI+сетка+уровни, фильтры, kill switch, реинвест |
| `advisor.py` | сигнальный помощник: 6 сетапов BTC, R:R 1:3, реинвест |
| `signal_engine.py` | движок сетапов: сигнал на 4ч, исполнение на 15м |
| `evolution*.py` | волны генетического отбора v1–v9 (walk-forward) |
| `patterns.py`, `smc.py` | детекторы графических паттернов и Smart Money |
| `webapp/` | сайт: боты, сигналы, PnL-кривые, эволюция, архив |
| `build_*.py` | пересчёт данных сайта после смены конфигов |

## Ключевые принципы

- **Честный бэктест-движок**: комиссии тейкер/мейкер, funding, проскальзывание,
  реальный порядок исполнения внутри свечи, ликвидации.
- **Walk-forward отбор**: каждый конфиг сдавал экзамены на данных, которых
  эволюция не видела; проваленные гипотезы честно задокументированы
  (классические паттерны, SMC, Fear&Greed — не прошли).
- **Реинвест**: маржа = 25% текущего капитала, не фикс.
- Бэктест ≠ будущее. Все цифры — симуляция; сначала DRY_RUN, потом деньги,
  которые не жалко.

⚠ Не финансовый совет. Торговля с плечом — риск полной потери средств.
