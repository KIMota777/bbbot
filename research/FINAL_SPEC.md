# Финальная конфигурация — зафиксирована ДО экзамена

Записано до того, как экзаменационная выборка была прочитана хоть раз.
После прогона на экзамене здесь не меняется ничего. Если результат окажется
плохим, он и будет ответом.

## Что торгуется

**Ансамбль из четырёх независимых правил**, отобранных по слабой связанности
недельных доходностей друг с другом (все попарные корреляции ниже 0.45,
большинство около нуля):

| правило | семейство | смысл |
|---|---|---|
| `c_willr` | одиночный индикатор | Williams %R: положение цены внутри диапазона последних n баров |
| `bos` | структура рынка | пробой последнего подтверждённого свингового экстремума |
| `vol_spike` | объём | всплеск объёма относительно своей средней |
| `supertrend` | тренд | смена стороны линии Supertrend (ATR-канал) |

Каждое правило торгуется **на всех пяти монетах одновременно**: BTCUSDT,
ETHUSDT, SOLUSDT, LTCUSDT, DOGEUSDT. Монета не выбирается — выбор монеты это
тоже подбор параметра, причём с пятью попытками.

Итого до 20 независимых «рукавов» (4 правила × 5 монет).

## Параметры исполнения

| что | значение |
|---|---|
| Таймфрейм | 4 часа (240 минут) |
| Риск на сделку | **0.43%** капитала на каждый рукав |
| Плечо | потолок ×10, фактическое — следствие риска и ширины стопа |
| Стоп | из ATR, ширина задаётся параметром правила |
| Комиссия | тейкер 0.055% на обе ноги |
| Проскальзывание | от 0.025% (BTC) до 0.06% (DOGE) |
| Фандинг | по фактической истории ставок |
| Одновременных позиций | до 20 (по одной на рукав) |

## Как выбираются параметры правил

Скользящая проверка вперёд: окно обучения 360 дней, окно применения 90 дней,
шаг 90 дней. На каждом окне для каждой монеты выбирается сочетание параметров
с лучшей **сглаженной по соседям** оценкой на обучающем куске — то есть плато,
а не пик. Выбор делается **только по данным строго раньше** окна применения.

Это правило продолжает действовать и на экзамене: параметры для
экзаменационных 169 дней выбираются по данным, заканчивающимся до начала
экзамена, и после этого не трогаются.

## Откуда взялась доля риска 0.43%

Подобрана двоичным поиском так, чтобы просадка на 95-м перцентиле блочного
бутстрэпа (10 000 прогонов) равнялась ровно 20% — потолку из задания.
Историческая просадка при этой доле составила 18.2%.

Риск здесь — не параметр доходности, а способ привести все кандидаты к одной
просадке, чтобы их вообще можно было сравнивать.

## Результат на обучении и проверке (внеобучающие куски)

| величина | значение |
|---|---|
| В месяц (среднее по кривой) | +2.88% |
| Медиана месяца | +2.71% |
| Плюсовых месяцев | 65% |
| Просадка историческая | 18.2% |
| Просадка Монте-Карло, 95-й перцентиль | 20.0% |

**Это НЕ цель задания.** Цель была +4–5% в месяц; достигнуто около +2.9%.
Задание на этот случай даёт прямое указание (раздел 53): не подгонять систему,
а взять устойчивый результат пониже. Он и взят.

## Что запрещено менять после экзамена

Всё перечисленное выше: состав ансамбля, список монет, таймфрейм, долю риска,
длину окон обучения и применения, правило выбора параметров, издержки.

## Ожидания

На экзамене результат почти наверняка окажется хуже. Причины известны заранее:
выбор этих четырёх правил из 61 сделан по результатам на обучении и проверке,
то есть сам является подбором с 61 попыткой; экзаменационный период —
медвежий, тогда как обучение пришлось на бычий рынок; 169 дней это слишком
мало для устойчивой оценки.

Насколько хуже — и есть вопрос экзамена.
